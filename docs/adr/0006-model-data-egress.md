# ADR-0006 · 允许项目数据发送至外部托管模型

| 项 | 值 |
| --- | --- |
| 状态 | Accepted |
| 日期 | 2026-08-03 |
| 决策者 | 项目负责人 |
| 关联需求 | FR-AI-014, NFR-COMP-004, NFR-COMP-007, NFR-SEC-005 |
| 解决问题 | Q-S1 |

## 背景

ProjectOS 的核心价值来自 Agent 能看到完整上下文：需求、架构、代码、决策、知识。
这些内容在数据分级中大多属于 `internal` 或 `confidential`。

如果 `confidential` 一律不出境，则只能使用私有化部署模型。代价是：

- 能力显著低于当前最强的托管模型，直接压低 Automation Rate 与采纳率
- 私有化部署与运维成本高，早期阶段不成立
- Agent 拿不到完整上下文时，产出质量下降，反过来损害用户对 AI 的信任

这是**能力与合规之间的取舍**，需要显式决策而非默认保守。

## 决策

**允许 `internal` 与 `confidential` 级别的数据发送至已批准的外部托管模型供应商。**

但出境是**受控**的，不是无条件的：

| 控制项 | 规则 |
| --- | --- |
| **供应商白名单** | 只允许发送至已批准的供应商端点；未在白名单的端点被网关拒绝 |
| **准入前置条件** | 供应商必须提供零训练留存（zero-retention）条款，数据不用于模型训练（NFR-COMP-007） |
| **PII 仍然脱敏** | `pii` 分级字段（邮箱、手机号、身份证、真实姓名等）在进入上下文前脱敏，**不随出境** |
| **凭据永不出境** | Secret / Token / 密钥类内容任何情况下不进入模型上下文 |
| **租户级开关** | 每个租户可将出境策略收紧至 `internal only` 或 `全部不出境`（切换到私有化模型通道） |
| **全量审计** | 每次出境记录：租户、AgentRun、涉及对象、最高数据分级、供应商、token 量 |
| **地域约束** | 若租户配置了数据驻留地域（NFR-COMP-002），只允许发送至同地域端点 |

### 分级出境矩阵

| 数据分级 | 默认出境 | 可否被租户关闭 |
| --- | --- | --- |
| `public` | ✅ | — |
| `internal` | ✅ | ✅ |
| `confidential` | ✅ | ✅ |
| `pii` | ❌ 脱敏后才可 | 不可放宽 |
| `secret`（凭据） | ❌ 永不 | 不可放宽 |

## 备选方案

| 方案 | 优点 | 缺点 | 未选原因 |
| --- | --- | --- | --- |
| A. confidential 不出境，仅用私有化模型 | 合规最稳 | 能力显著下降；私有化成本高；Agent 上下文残缺 | 直接削弱产品核心价值 |
| B. 完全无限制出境 | 实现最简单 | 凭据与 PII 泄漏风险；无法向合规客户交代 | 风险不可接受 |
| **C. 受控出境（白名单 + PII 脱敏 + 租户开关 + 审计）** | 保住能力，风险有边界，客户可自主收紧 | 需要维护白名单与分级标注；数据分级的准确性成为前置依赖 | **已选** |

## 后果

### 正面

- Agent 可获得完整上下文，产出质量与 Automation Rate 不被人为压低
- 无需在早期投入私有化模型部署与运维
- 出境边界清晰、可审计，将来面对合规客户时有据可查
- 租户开关的存在意味着：单个客户要求收紧时，是配置变更而非架构改造

### 负面 / 代价

- **依赖数据分级的准确性**：分级标注错误会导致本不该出境的内容出境。分级质量成为关键前置
- 面向强监管行业（金融、政务、医疗）销售时，仍需私有化模型通道，届时是额外工作量
- 供应商侧的安全事件会波及项目数据，风险不完全可控
- 审计与出境记录本身产生存储成本

### 需要后续处理

- [ ] 数据分级的自动标注与人工复核机制（分级准确性是本决策的基础）
- [ ] PII 检测与脱敏管道，进入 Agent 上下文前强制执行
- [ ] 供应商白名单管理与准入评估流程（含零留存条款核验）
- [ ] 出境审计看板：按租户/供应商/分级统计
- [ ] 私有化模型通道预研，作为强监管客户的替代路径（Q-I4 相关）

## 验证方式

- 自动化测试：向未在白名单的端点发送请求必须被拒绝
- 自动化测试：`pii` 字段在上下文快照中必须已脱敏
- 自动化测试：凭据类内容在任何路径下都不进入模型上下文（上下文快照扫描）
- 自动化测试：租户开关切换为「不出境」后，外部模型调用全部被拒绝并降级
- 审计抽查：每次出境均有完整记录，可按租户与分级检索
